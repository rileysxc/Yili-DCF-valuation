## 一、这个仓库做什么

存放伊利估值报告的取数与数据处理代码，共 **24 个可复用脚本**，覆盖全流程：

1. **取数**——从 AKShare 拉取原始数据（`600887_pipeline.py`、`fetch_stock_data.py`），原样落 01/02/03 层。
2. **清洗**——把三家口径统一成一张可比的表，落 **07 层**（`build_clean_layer.py`），并做缺失值/异常值体检（`audit_data_quality.py`）。
3. **指标与同业**——基础趋势表、PE/PB 历史分位、同业对比（`build_trend_table.py`、`build_valuation_percentiles.py`）。
4. **估值与图表**——DCF 结果读取、敏感性矩阵、六类图表（`make_*_charts.py`）。
5. **交付**——报告 DOCX 生成、文档引用复核（`build_final_report.py`、`check_doc_refs.py`）。

> 位置：`估值分析报告/代码仓库/git代码/`，本目录就是 git 仓库根。
> 数据、资料、文档都在上两级目录，不属于本仓库；脚本运行时仍按项目结构读写
> `../../原始数据/`、`../../数据文件/` 等。

### 仓库边界（什么进 git、什么不进）

**约定：本目录既是工作目录，也是 git 仓库根。** 只跟踪「整理过、可复用的 .py 脚本」，
Notebook 形式的代码放在 `../我的代码/`，一次性探路脚本用完即删，运行产生的数据不进仓库。

| 类别 | 去处 | 说明 |
| --- | --- | --- |
| 可复用脚本（本目录内的脚本文件） | 进 git | 一个脚本一个用途；功能变化时更新本 README |
| Notebook 形式的数据处理代码 | 不进 git | 放在 `../我的代码/`，与脚本分开保存 |
| 一次性探路脚本 | 不进 git | 用完即删，不留档 |
| 数据与图表（`../../原始数据/`、`../../可视化图表/`） | 不进 git | 由脚本生成，靠 `_日期_RevNN` 管理版本 |
| 文档（`../../数据文件/`、`../../报告文件/`） | 不进 git | 另行归档 |
| 原始资料（年报 PDF、研报） | 不进 git | 版权与体积问题，引用时写明来源即可 |

代码的版本靠 **git 提交历史**管理，文件名**不必**带日期与版本号；
`_日期_RevNN` 这套命名只用于数据文件。

## 四、脚本说明

### 1. `600887_pipeline.py` —— 伊利主流水线

一条命令跑完从取数到导出的全流程，**不依赖 notebook**。

```bash
python 600887_pipeline.py
python 600887_pipeline.py --out "D:\备战金融分析\实习资料\估值分析报告\原始数据"
python 600887_pipeline.py --rev Rev01        # 重出时提高版本号
```

四个步骤，任一环节不通过就中止，**不导出部分数据**：

1. **取数**——9 个数据源，逐个记录成功/失败，失败会列出原因并中止。
2. **统一日期 + 筛选**——日期列统一为 `datetime64[ns]`、列名 `date`、置于第一列；财报筛到 7 个报告期，行情与估值筛到 2021-01-01 ~ 2026-10-09。
3. **一手锚点校验**——用 2026 年半年报披露的数字校验 5 个关键字段，对不上就中止（见下）。
4. **导出**——10 个 CSV + 1 个 Excel（7 页签）+ manifest。

**一手锚点**（来源：《2026 年半年度报告》p6 / p10）

| 字段 | 报告期 | 期望值 |
| --- | --- | --- |
| 营业收入 | 2026-06-30 | 643.31 亿元 |
| 营业总收入 | 2026-06-30 | 644.90 亿元 |
| 营业成本 | 2026-06-30 | 408.94 亿元 |
| 经营活动产生的现金流量净额 | 2026-06-30 | 97.59 亿元 |
| 归属于母公司股东权益合计 | 2026-06-30 | 537.11 亿元 |

**产出**（按数据层落盘，见下节「数据层结构」）

```text
00_索引/export_manifest_<日期>_<rev>.json
01_报表原表/600887_伊利股份/600887_{资产负债表,利润表,现金流量表,财务指标,财务摘要,财务摘要_全量}_<日期>_<rev>.csv
02_行情数据/600887_伊利股份/600887_行情_<日期>_<rev>.csv
03_估值数据/600887_伊利股份/600887_{估值,估值十年PE,估值十年PB}_<日期>_<rev>.csv
06_建模用Excel/600887_财务数据_<日期>_<rev>.xlsx
```

**CSV 与 Excel 的分工**：CSV 保留接口原样，定位「原始数据层」；Excel 做转置整理，定位「建模用」——三张表和财务指标都转成**科目为行、报告期为列**，可直接搭 DCF。Excel 另有「估值日频」（含总股本、市值，供 WACC 使用）和「口径说明」（把口径写进文件本身）两个页签。

**不覆盖同名文件**，已存在会打印 `[跳过·同名已存在]`。

## 七、口径约定（重要）

报告全篇不得中途更换以下口径。更详细的版本见 `数据文件/数据口径与待办提醒/` 目录下的最新版。

**消费层**：下游一律读 `07_清洗后数据/`。该层已把三家统一成：首列 `date` + ISO 字符串、报表 8 个报告期、市场类 2021-01-01~2026-10-09（1,395 个交易日）、`估值十年PE/PB` 数值列名统一为 `pe_ttm`/`pb` 且只留 > 0。

**营收主口径**：营业收入（不含利息收入），2026H1 = 643.31 亿元。含利息收入的营业总收入 644.90 亿元仅作对照。

**报告期取 8 期**：2020-12-31、2021-12-31、2022-12-31、2023-12-31、2024-12-31、**2025-06-30**、2025-12-31、2026-06-30。
其中两个基数不能省——2020-12-31 用于算 2021 年同比与 ROE 期初净资产；2025-06-30 用于算 2026H1 同比。**中期只能与中期比，不能与年度比。**
财务指标接口的 `start_year` 必须设为 `2020`，设为 `2021` 会漏掉 20201231。

**数据截止**：市场数据（行情、估值）截至 2026-10-09；财报最新期为 2026-06-30（2026 三季报尚未披露）。

**估值区间的合成规则（2026-10-16）**：最终合理价值区间 ＝ DCF（主口径）∩ PE 5 年日频分位隐含价带（交叉验证）；PE 10 年周度分位只作窗口稳健性检验、PB 两个窗口只作辅证，**均不参与合成、PB 也不作价值下限**。「主／稳健」只用于 PE 行的合成角色命名，PB 行只按窗口命名，避免与分位表的窗口名混淆。隐含价分母：PE 用 TTM EPS 1.6004 元/股、PB 用 BVPS 8.4914 元/股；分位口径一律为占比法（P ＝ 样本中 ≤ 当前值的个数 ÷ 样本总数）。

**金额单位**：原始数据为「元」，未做换算；报告正文统一用「亿元」。

**三个必须注意的字段陷阱**：

1. 财务摘要的「营业成本」实为**营业总成本**。算毛利率必须用**利润表**的「营业成本」，否则得到 14.51%，正确值是 36.43%。
2. 现金流量表有两列相似字段：`经营活动产生的现金流量` **整列为空**，要用 `经营活动产生的现金流量净额`。
3. 行情表的 `outstanding_share` 是**流通股本**（62.94 亿股）；总股本 63.25 亿股在估值表里。

**日期类型有两族**：三表与财务摘要是 `str`（`'20260630'`，需指定 `format='%Y%m%d'`）；财务指标、行情、估值的日期是 `datetime.date` 对象，**不是字符串**，用 `== '2021-03-31'` 比较会全部为 False。
